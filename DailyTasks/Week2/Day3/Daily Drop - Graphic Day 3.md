## Section B: The Execution Mandate (9:00 AM - 2:00 PM)

### 1. Execution Summary (TL;DR)
Objective: Convert your Day 2 wireframe into a complete high-fidelity Figma UI. Apply a consistent colour system, typography scale, spacing grid, and reusable component library. The result must be a production-ready design that a developer could implement directly.

### 2. The Workflow:

9:00 AM - 10:00 AM (Learning): Watch all three videos. Study the Material Design 3 component library for button, card, navigation, and data table patterns. Browse Dribbble dashboard inspiration for 20 minutes — save 3 references to a Figma board.

10:00 AM - 1:00 PM (Building):
Action 1 (Design System Setup): Create a "Design System" page in your Figma file. Define: Colour palette (Primary, Secondary, Surface, On-Surface, Error — 5 semantic colours minimum), Typography scale (Display/H1/H2/Body/Caption — 5 styles), Spacing tokens (4px grid — 4, 8, 16, 24, 32, 48, 64), and a component library with at minimum: Button (3 variants), Card, Input Field, Navigation Item.
Action 2 (Hi-Fi Screens): Convert your Day 2 wireframe to hi-fi. Apply all design system tokens. Use Auto Layout for every component and frame — no manual pixel-nudging. Screens required: Dashboard/Home, Detail/View, and one Form screen.
Action 3 (Prototype): Connect all three screens with Figma prototype interactions (click-through, hover states on buttons, overlay for a modal). Export screen assets at 2x PNG for the GitHub submission.

The Non-Negotiable Rules:
1. Every component must use Auto Layout — static frames are not acceptable.
2. All colours must come from your Design System — no ad-hoc hex values in components.
3. Your prototype must be shareable via Figma link — test the public "Anyone with link" permission before submission.

1:00 PM - 1:30 PM (Hygiene): Name every layer and frame properly (no "Frame 47" or "Rectangle 12"). Group related layers. Run the Figma "Accessibility Checker" plugin — all text must pass contrast ratio WCAG AA.

1:30 PM - 2:00 PM (LinkedIn): "Day 3 design at ProSensia — turned wireframes into hi-fi with a proper design system. Auto Layout is a game-changer: components that resize intelligently instead of breaking. Sharing my Figma prototype link."
